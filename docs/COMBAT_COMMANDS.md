# RIFTWALKER: FALSE PROPHET
## Combat Command Reference

MOVEMENT
- WASD = Move

CORE COMBAT
- Left Click = Basic Attack
- X = Dash / Interact
- O = Weapon Manifest
- Triangle = Protocol Activation

ADVANCED COMBAT
- R + Attack = Quick Skill
- L = Target Lock

WEAPON CONTROL
- < = Previous Weapon
- > = Next Weapon
